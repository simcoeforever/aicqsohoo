# English and Japanese explanation and experiment pages

Existing English paths and machine-readable interfaces remain unchanged. Japanese
explanation and experiment pages live under /ja/about/ and /ja/experiment/.
Language switches link to the matching page. Canonicals remain language-specific,
and paired pages include English/Japanese hreflang alternatives and HTML lang.

Weekly reports generate both languages in one JSON file from the same validated
summary, controlled-test records and reviewed public intervention summaries. The
English fields remain at the original top level; Japanese fields are in
translations.ja. Existing immutable English articles use reviewed companion files
in data/report-translations/ja, including the first generated closed week.

No external translation service, credentials or cost are added. Fixed Japanese
templates preserve dates, count bands, suppression and uncertainty. Intervention
text uses public_summary_ja when reviewed; otherwise the reviewed English source
is shown with an explicit untranslated label. Raw notes are never translated or
published. A new manually authored article requires a reviewed Japanese companion;
a missing translation stops the build rather than claiming a completed translation.

Japanese and English variants map to the same public measurement page category.
No language identifier or new demographic combination is stored. The JSON/API
interfaces retain English canonical URLs and their established schemas.
